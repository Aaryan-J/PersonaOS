# PersonaOS
__PersonaOS__ is a web-based OS ispired from Persona 3 Reload. It's in the early stages of development right now and will be completed and shipped over time.

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/6009412a-a0cf-4dea-87be-b8e01dd1b00d" />

## Features
__PersonaOS__ currently has cool animations and other features which are listed below:
1. Hover and click animations on menu buttons similar to the Persona 3 Reload menu.
2. Hover and click animations on tab buttons inside windows.
3. Draggable and closable windows.
4. A working clock in the top bar.
5. Animated lists inside windows for content.
