# PersonaOS
__PersonaOS__ is a web-based OS inspired from Persona 3 Reload.

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/6009412a-a0cf-4dea-87be-b8e01dd1b00d" />

## Features

### UI
- Menu Animations: Hover and click animations on menu buttons similar to the Persona 3 Reload menu.
- Windows: Draggable and closable windows.
- Custom Persona 3 Theme: A custom theme inspired by the Persona 3 Reload menu theme.
- Animations: Animations for window transitions and UI elements.

### Audio
- UI SFX: Sound effects for UI interactions.
- BG Music: Background music for the OS from the original game.

### Music App
- Track List: An extensive list of music tracks from the original persona games!
- Playback Controls: Play, pause, stop, and skip controls for the music player.

### Calendar App
- Event Scheduling: Schedule and manage events on the calendar with the task scheduler.
- Persistant Storage: Event data is stored persistently on the user's device in localstorage.
- Date and Day display

## Built with
- HTML
- CSS
- JavaScript
