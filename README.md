# PeronsaOS
__PersonaOS__ is a web-based OS ispired from the Persona 3 game. It's in the early stages of development right now and will be completed and shipped over time.

### Features
__PersonaOS__ currently has only a draggable window and a cool watch that tells the current time but not to worry as more stuff will be added soon! 
Look below for planned features!

### Future Plans
Currently __PersonaOS__ is in development but these features will be implemented:

1. 3 apps (for now)
    - Music [This will link to my favourite artists and their albums]
    - Books [This will link to my favourite authors and books]
    - Media [This will link to my favourite shows, mostly anime, and movies]  
2. A Persona 3 styled menu
3. Cool animations
